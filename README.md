# Fixed JSON Auth Server

Deploy this folder to the Render service currently used by the website:
https://my-json-auth-server-1.onrender.com

Start command: `npm start`

Default accounts:
- Admin: `uk0wme` / `ilobyou`
- `ankit` / `gupta`
- `rajj` / `rajj`
- `john` / `john7698`

The server provides `/login`, `/verify-session`, `/register`, `/users`, and `/users/:username` and includes CORS plus a health response at `/`.
